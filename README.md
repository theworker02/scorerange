# scorerange

Score timestamps and range durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/scorerange/

## Install / run

```bash
git clone https://github.com/theworker02/scorerange.git
cd scorerange
node src/cli.js
node --test
```
